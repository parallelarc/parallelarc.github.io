# For agents

This is Foxiv's personal website and blog, published as **parallelarc** on GitHub.
Read the original GitHub content using the links below.

## Find content

- [Blog articles](https://github.com/parallelarc/parallelarc.github.io/issues?q=is%3Aissue%20is%3Aopen%20label%3Ablog): open Issues with the `blog` label. Use titles and additional labels to select relevant articles; `podcast` identifies interview notes.
- [Biography and projects](https://github.com/parallelarc/parallelarc.github.io/tree/main/src/content/siteData): the public facts used by both website modes.
- [Site overview](../README.md): navigation and features.
- [GitHub profile](https://github.com/parallelarc): public projects and profile.

The [Issues API](https://api.github.com/repos/parallelarc/parallelarc.github.io/issues?state=open&labels=blog&per_page=100)
also provides article titles, Markdown bodies, labels, dates, and source URLs.
Follow pagination for the full collection and exclude entries with `pull_request`.
Closing an Issue or removing its `blog` label withdraws it from the website after
the next successful content update.

## Read and cite

- Cite the original Issue URL and article title; preserve article language.
- Interview participants' views and cited researchers' claims belong to those
  sources. Distinguish them from the publisher's commentary; publication does not
  by itself imply endorsement or original authorship of every idea.
- `created_at` and `updated_at` describe the GitHub record. They do not establish
  the interview date or when a claim was last checked. Preserve historical context.
- Use explicit public biography/project descriptions for personal facts. Do not
  infer responsibilities or achievements from an institution or project link.

This guide is for reading public content. [AGENTS.md](../AGENTS.md) contains
instructions for agents making changes to the code repository.
